# 获取与换电脑复用

本技能保存整理方法与可调整的目录模板，不包含原始资料、账户配置、运行环境或既有移动清单。换电脑后重新盘点实际文件，不执行旧电脑的移动计划。

## 获取完整技能

从技能的 GitHub 仓库下载源码或发布 ZIP。源码中使用 organize-workspace 子目录；技能 ZIP 解压后也应得到一个 organize-workspace 目录，内部含 SKILL.md、agents 和 references。Notion 可以作为说明或下载入口，但不是运行依赖。

先查看版本和内容，再把完整技能目录交给具有本地文件访问能力的 AI。指定实际目标根目录，并说明只生成方案还是实际整理。保存到 GitHub 或 Notion 不等于自动安装，也不会赋予文件访问权限。

## Codex 本地安装

按 [OpenAI 官方技能文档](https://learn.chatgpt.com/docs/build-skills)（核对日期：2026-09-14），可将整个 organize-workspace 文件夹放入用户级 ~/.agents/skills，或项目级 .agents/skills。也可以让目标环境中的 skill-installer 从 GitHub 仓库安装 organize-workspace 子目录，并核对其实际安装结果。

不同版本可能保留其他发现路径；以目标工具当前支持的位置为准，避免同名技能装入多个目录。已有同名技能时先比较版本与本地修改，不直接覆盖。更新后确认技能能被发现；必要时重新启动工具。

不安装时，也可以直接把 SKILL.md 路径交给 AI，要求本次读取使用。agents/openai.yaml 是 OpenAI 产品的界面元数据，不代表其他工具已验证兼容。

## 可复制的请求

只生成方案：

> 读取我提供的 organize-workspace/SKILL.md。目标是我本次指定的工作目录，先只读盘点，给出统一分类和旧路径到新路径的移动清单，不修改文件。

实际整理：

> 使用 organize-workspace 整理我指定的目录。统一同类子文件夹，按实际内容归位，保留原件和所有版本。完成盘点、移动清单与必要备份后，直接执行明确且安全的项目；归属不明或依赖外部配置的项保留并说明。更新导航和引用，校验后交付记录。

已安装且支持美元符号调用的工具，可使用 $organize-workspace；否则直接提供技能路径。更换电脑后应重新明确根目录与范围。

## 环境与验证范围

版本：1.1.1，实验版，2026-09-24。运行整理需要 AI 的文件读写和终端能力；Python、Git 或文档解析器按待处理文件需要使用。技能没有自动搬移或自动回滚程序，执行与恢复依赖 AI 按记录逐项核对。

Windows、macOS 和 Linux 的权限、大小写、保留名称、符号链接和路径长度规则不同。当前行为验证仅涵盖 macOS 隔离环境中的虚构资料，具体案例、结果与未验证项见发布仓库 tests/RESULTS.md。仓库中的测试工具只用于构造和检查虚构案例，不要指向真实工作目录。其他系统、其他 AI 工具及真实同步服务的并发行为尚未验证。
